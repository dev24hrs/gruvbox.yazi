# gruvbox-classic.yazi

Local Yazi flavor using the **Gogh Gruvbox Dark** palette, matching WezTerm's built-in
`Gruvbox Dark (Gogh)` color scheme.

## Palette

| Role | Hex |
| --- | --- |
| Background | `#282828` |
| Foreground | `#ebdbb2` |
| Bright red | `#fb4934` |
| Bright green | `#b8bb26` |
| Bright yellow | `#fabd2f` |
| Bright blue | `#83a598` |
| Bright magenta | `#d3869b` |
| Bright aqua | `#8ec07c` |
| Bright orange | `#fe8019` |

Sources:

- <https://gogh.website>
- <https://github.com/Gogh-Co/Gogh/blob/master/themes/Gruvbox%20Dark.yml>
- <https://yazi-rs.github.io/docs/flavors/overview>

## Usage

```toml
[flavor]
dark  = "gruvbox-classic"
light = "gruvbox-classic"
```
