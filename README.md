# gruvbox.yazi

Local Yazi flavor using the **Gogh Gruvbox Dark** palette, matching `Gruvbox Dark (Gogh)` color scheme.

<img src="https://images.dev24hrs.top/blog/2026-11-08-0105837c8afbfeb1.png" alt="image-20261108200159204" style="zoom:50%;" />

## Installation

**Using package manager**

```bash
ya pkg add dev24hrs/gruvbox.yazi
```

## Usage

```bash
[flavor]
dark = "gruvbox"
light = "gruvbox"
```

## Palette
